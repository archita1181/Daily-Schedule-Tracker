# Daily Schedule Tracker

A simple and user-friendly web application designed to help users manage their daily tasks, organize schedules, and improve productivity.

## Features

- Add and manage daily tasks
- Track scheduled activities
- Mark tasks as completed
- Simple and user-friendly interface
- Helps organize daily routines

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Project Structure

daily-tracker-app/
├── src/
├── public/
├── package.json
└── vite.config.js

## How to Run

1. Clone the repository
2. Open the project folder
3. Install dependencies
4. Start the development server
